# Security Policy

## Reporting A Vulnerability

Do not report vulnerabilities through public issues.

Use one of the following private channels instead:

- GitHub Security Advisories for this repository
- a private maintainer contact channel

Include the affected component, impact, reproduction steps, and any supporting logs or proof of concept.

## Secrets Hygiene

Never include real bot tokens, API keys, service-account credentials, or production identifiers in issues, pull requests, screenshots, or logs.
